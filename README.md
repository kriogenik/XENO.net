# XENO.net

Личный доступ в сеть. Единственный приоритет — **цифровая приватность**.

Не общий VPN и не маркетинг «невидимости» — спокойный канал наружу и открытый код, который можно проверить самому.

## Начать пользоваться

1. Telegram: [@xenonet_bot](https://t.me/xenonet_bot)  
2. Клиент: [Happ](https://www.happ.su/)  
3. В боте: **Подключиться за 1 минуту** → устройство → демо → подписка в Happ  

Инструкции: [документация](docs/README.md) · [бот](docs/bot.md) · [Happ](docs/happ.md)

## Зачем открытый код

Чтобы не верить на слово. Можно увидеть, как выдаётся доступ и чего бот не делает.

→ [Почему репозиторий открыт](docs/open-source.md) · [Как это работает](docs/how-it-works.md) · [О сервисе](docs/about.md) · [Политика](docs/policy.md)
