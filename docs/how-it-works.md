# Как это работает

Коротко и без внутренней кухни: куда идёт трафик и что вы получаете в боте.

## Путь трафика

```
Ваше устройство (Happ)
        │
        ▼
   Входной мост (РФ)
        │
        ├─ сайты РФ (и Ozon/Magnit) ──► напрямую
        │
        └─ остальное ──► выход за рубежом ──► интернет
```

В подписке обычно два профиля:

1. **Основной** — через мост (удобнее под местным DPI; РФ-сервисы идут напрямую с моста).  
2. **Запасной** — прямой вход на выходную ноду, если мост недоступен.

Для магазинов вроде Ozon/Magnit выбирайте профиль **RU**, не NL Direct — иначе выход будет зарубежным.  
Happ сам выбирает живой профиль; после обновлений сети — **обновите подписку**.

## Что вы получаете в боте

Не «конфиг руками», а **ссылку подписки**.  
Клиент подтягивает актуальные параметры. После обновления сети достаточно обновить подписку в Happ (иногда — удалить старый профиль и добавить URL заново).

## Что можно проверить в коде

- как бот выдаёт доступ и второе устройство (`bot/`);  
- как собирается список профилей для Happ;  
- что бот не лезет в чужие сервисы на той же машине.

Подробнее о доверии: [open-source.md](open-source.md).
