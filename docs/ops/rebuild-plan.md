# План восстановления контура

> Для операторов и self-host. Клиентам XENO не требуется — см. [../README.md](../README.md).

Если продуктовый стек снесён, а на exit остаются чужие сервисы:

1. Не трогать панель/сторонние bot’ы.  
2. Поднять заново relay + entry по `deploy_two_node.py`.  
3. Выложить бота `deploy_bot.py`.  
4. Проверить e2e exit IP = ваш `NL_EXIT_IP` из локального inventory.  
5. Пользователям — обновить подписку (токены лучше сохранить, если БД цела).

Шаблоны: `configs/xray/`. Секреты — только локально.
