# Чеклист заказа серверов

> Для операторов и self-host. Клиентам XENO не требуется — см. [../README.md](../README.md).

Шаблон для оператора. Реальные IP/пароли сюда не записывать в git — только в локальные заметки или `secrets/`.

## Минимальный контур

| Роль | Где | Что проверить |
|------|-----|----------------|
| Exit (NL или аналог) | VPS за рубежом | SSH, публичный IP, можно ли открыть hop-порт только с entry |
| Entry (RU или аналог) | VPS в зоне DPI | SSH, DNS на entry-hostname, порт 443 свободен/под ваш Xray |

## После заказа

1. Заполнить `inventory/hosts.local.env` (скопировать с `hosts.env`).  
2. Положить SSH/токены в `secrets/`.  
3. Следовать [two-node.md](two-node.md) / `scripts/deploy_two_node.py`.  
4. Не коммитить `hosts.local.env` и `secrets/*`.

## Не делать

- Не светить IP и панель в Issues/PR.  
- Не вносить чужие inbound’ы панели в автоматизацию бота.
