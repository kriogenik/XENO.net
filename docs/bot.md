# Бот

Telegram: [@xenonet_bot](https://t.me/xenonet_bot)

## За минуту

1. **/start**  
2. **Подключиться за 1 минуту** — выберите устройство  
3. Установите **Happ** (кнопка магазина под вашу платформу)  
4. **Открыть демо** — получите ссылку подписки  
5. В Happ: открыть / вставить ссылку → обновить → включить VPN  

Готово. Внешний IP будет «зарубежным»; сайты РФ — напрямую, без лишнего обхода.

## Мой доступ

- срок и статус;  
- ссылки подписки в тексте (нажмите, чтобы скопировать);  
- при одной ссылке — **Открыть подписку** и **Второе устройство** (вторая ссылка, первая не меняется);  
- при двух ссылках — только **Убрать устройство 2** (с подтверждением); открывающих кнопок нет, ссылки в тексте; первая ссылка и срок не затрагиваются.

Кнопки **Устройство 1 / Устройство 2** больше не используются. Если видите их в старом сообщении — отправьте **/start**, затем снова откройте **Мой доступ** (очищать чат не нужно): бот пришлёт свежий экран с актуальными кнопками.

Демо — один раз на Telegram-аккаунт, на фиксированный срок.  
Повторное «Открыть демо» покажет уже выданную ссылку, если доступ ещё активен.

## Тарифы

Оплата пока закрыта.  
Можно нажать **Узнать первым об оплате** — запишетесь в лист ожидания в этом же чате, без сторонних рассылок.

## Если не коннектится

1. Выключите VPN в Happ.  
2. Удалите старый профиль XENO.  
3. Возьмите свежую ссылку из **Мой доступ** → добавьте заново → обновите.

Статус сети — кнопка **Статус** в боте (без внутренних деталей серверов).

## Поддержка и код

В **Поддержке** — публичный репозиторий на GitHub: можно убедиться, как устроена выдача доступа, не «на слово».  
Кнопка **GitHub · открытый код** ведёт на [github.com/kriogenik/XENO.net](https://github.com/kriogenik/XENO.net).

**Политика** — кнопка на главном экране: данные не товар, без продажи логов и «партнёров». Полный текст: [policy.md](policy.md).

Если сервис полезен — в **Поддержке** есть **Поддержать** (крипто, без обязательств). Адреса показываются только когда они заданы.

## Написать нам

Если шаги из поддержки не помогли — в **Поддержке** есть **Написать нам** (или команда `/dialog`).

Сначала короткий экран с самопомощью, затем можно описать, что видите в Happ (текст или скрин).  
Ответ придёт **в этот же чат** — без сторонних форм и ботов.

Не присылайте ссылку подписки целиком: для диалога она не нужна.  
Закрыть диалог можно кнопкой в чате.
