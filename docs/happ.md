# Клиент Happ

XENO рассчитан на приложение [Happ](https://www.happ.su/) (iOS, Android, Windows, Mac).

## Установка

Кнопки магазинов даёт бот после выбора устройства.  
Или напрямую:

- [App Store](https://apps.apple.com/ru/app/happ-proxy-utility/id6783623643)  
- [Google Play](https://play.google.com/store/apps/details?id=com.happproxy)  
- [Windows](https://github.com/Happ-proxy/happ-desktop/releases/latest/download/setup-Happ.x64.exe)  
- [сайт Happ](https://www.happ.su/)

## Подписка, не «один ключ»

1. В боте откройте **Мой доступ** → скопируйте URL из текста (при одной ссылке можно **Открыть подписку**).  
2. В Happ добавьте **ссылку подписки**.  
3. Обновите подписку.  
4. Включите VPN.

Ссылка должна начинаться с `https://` (на любой ОС; cleartext `http://` Happ не принимает / на TLS-порту ломается).

В списке два профиля: **🇷🇺 RU** (основной) и **🇳🇱 NL Direct** (запасной).  
**Выберите RU вручную** — автовыбор часто переключает на Direct, и кажется, что «RU сдох».

## Частые проблемы

| Что видите | Что сделать |
|------------|-------------|
| Ошибка про insecure / HTTP / unexpected end of stream | Удалить старый XENO в Happ, взять свежую ссылку из бота (`https://…`) |
| «Неизвестный тип контента» / Unknown content type (часто iOS) | Та же `https://…` ссылка; удалить профиль XENO в Happ и добавить URL заново (тело — список `vless://`, не base64) |
| «В разрешении отказано» / permission denied (часто iOS) | Сначала: удалить профиль XENO в Happ и добавить ссылку из бота заново. Если снова: Настройки → Happ → разрешить VPN / конфигурацию VPN, затем повторить импорт |
| Пусто / не коннектится после сбоя сети | Удалить старый XENO, добавить ссылку из бота заново |
| «Вроде подключено», сайты не открываются | Обновить подписку; проверить, что VPN именно XENO |
| Магазины (Ozon/WB/Магнит/X5/Лавка/…) видят VPN | Выбрать профиль **🇷🇺XENO RU**, не NL Direct; обновить подписку. На entry CDN магазинов уходит в direct. Банки/Госуслуги обычно уже идут напрямую |
| Обновляли подписку при включённом VPN | Выключить VPN → обновить → включить |

## Windows (Happ Desktop)

Та же `https://…` подписка, что на телефоне. Если на Android сеть есть, а на ПК нет — обычно не сервер, а режим Happ на Windows.

1. Скачайте свежий [Happ x64](https://github.com/Happ-proxy/happ-desktop/releases/latest/download/setup-Happ.x64.exe) и **запускайте от имени администратора** (TUN без прав админа часто «подключён», но трафик не идёт).
2. В боте: **Мой доступ** → скопируйте **вторую** ссылку (не первую) → импорт ссылки подписки в Happ, не одного сырого `vless://`.
3. VPN **выкл** → обновить подписку → выбрать профиль **🇷🇺XENO … RU** (или NL Direct) → включить.
4. Если TUN не даёт сеть: отключить → режим **Proxy** (или Mixed) → снова включить. Браузер должен ходить через системный прокси.
5. Windows Firewall / антивирус: разрешить Happ; при сомнении временно отключить фильтр и проверить.
6. Запасной клиент: **v2rayN** + та же ссылка подписки.

## Важно

URL подписки = доступ к вашей сети. Не пересылайте и не публикуйте.
